当前程序 **0.18**，正式动画 **v18**：25段、891张透明PNG。C# / WPF / .NET Framework4.8，功能实现与桌面适配、动画、设置分别管理。

[下载最新 Release](https://github.com/resonaaaaa/ArcPet/releases/latest) · [全部动画](preview.html) · [跳舞双向预览](design/actions-v12/review.html) · [使用说明](app/USAGE.txt)

## 已完成

- 解锁时左键按住0.5秒拎起，拖动后松手落地。支持Ctrl+左键上下缩放（0.4x—2x），锁定位置和大小；右键/托盘显示隐藏、睡眠、移动模式、自启动开关；设置自动记忆。
- 待机60—90秒随机触发进食、思考、音乐、做操、电话；做操2轮、思考3轮、其余5轮。满足睡眠条件后等待当前动作结束。
- 每次实际进入睡眠时，1/3概率趴下摇尾巴，2/3概率原睡姿；都在左右键点击或睡满2分钟时结束，趴姿不加入普通随机动作池。
- 移动仅在未锁定、启用移动且有安全空间时触发；抽中移动后滑板/散步各1/2，行程内不重抽。长程到边缘，短程5w往返，任意鼠标输入立即停位。
- 锁定/未锁定双击均跳舞，每次随机起始朝向，每3轮镜像一次，1秒/轮、12轮；锁定0.5秒长按蹲跳、1.5秒长按进入火箭蓄力，松手发射归位。
- 普通动作和跳舞可由有效双击或长按抢断。解锁长按拎起，锁定长按蹲跳。滑板/散步的移动打断独立处理。
- 待机/思考气泡、15个像素图案、三云依次淡入。程序只显示托盘入口，不占任务栏。
- 跳舞保留身体前后换重心，修订发色、头型及尾巴，增加镜像。观感仍以用户实机验收为准。

## 0.18 · 长按拎起与拖动

解锁时按住猫姬左键满500毫秒即可拎起。猫姬在拎起开始后的约240毫秒内把后领移到光标下，之后每帧都对准后领抓点。松手后在选定位置落地。快速松手时会缩短剩余拎起动作，悬挂时松手会沿当前摆动返回落地起点。扩展画布按原角色比例绘制，给头顶离地动作留出空间。
