## 抽签与开机启动修复

- 从猫姬右键菜单或托盘选择「抽签」，猫姬会摇筒、提签，并用气泡显示七种签等之一。每日按系统本地时间 06:00 刷新，同一天可反复抽签，重启后结果也保持一致。
- 安装新版并打开一次后，已开启的开机自启动会从旧版或失效路径迁移到新版。原本关闭则继续关闭；打开支持迁移的旧版不会用它替换新版的启动路径。

升级时先退出旧版，完整解压 Windows 便携 ZIP，再运行 `ArcPet.Preview.exe`。需要 Windows 和 .NET Framework 4.8。若希望保留旧版的大小、位置等偏好，可将旧目录的 `data` 文件夹复制到新版目录，或关闭旧版后在同一目录覆盖升级。SHA-256 文件可用于核对下载。
