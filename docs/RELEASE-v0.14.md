# ArcPet v0.14

Windows 桌宠便携版，需要 .NET Framework 4.8。下载 `ArcPet-v0.14.zip`，完整解压后运行 `ArcPet.Preview.exe`，保留同目录 DLL、config 和 assets。首次运行使用默认设置，个人偏好不包含在发行包中。

- 跳舞每三轮切换镜像：随机起始方向，按 A×3 → B×3 → A×3 → B×3 播放，共12轮、约12秒。
- 镜像在第3、6、9秒完成整轮后切换，保持原有帧序和节奏；双击重新触发会开始新批次。
- 锁定/未锁定双击均可跳舞；长按、拖动、滑板独立打断、思考气泡与睡眠排队逻辑保留。
- 含缩放、锁定、设置记忆、托盘、开机启动、随机动作、滑板移动及火箭交互。

检查：624项核心、204项窗口回归，共828项；19段动画、740张透明PNG。窗口检查使用WPF控件和生产输入适配方法，不代表所有显示器环境的实机验收。
