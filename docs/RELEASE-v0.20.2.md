## 番茄钟阅读节奏

- 每 10～12 秒随机翻页一次，保留完整的 23 帧翻页动作。
- 眨眼频率减半，平均约 3.74 秒眨一次。两次翻页之间继续播放呼吸动画。
- 暂停或结束时，等当前呼吸或翻页片段结束后衔接。

下载 Windows 便携 ZIP，完整解压后运行 `ArcPet.Preview.exe`。需要 Windows 和 .NET Framework 4.8。SHA-256 文件可用于核对下载。
