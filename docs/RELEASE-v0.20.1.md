# ArcPet v0.20.1 · 番茄钟与像素时间气泡

- 新增番茄钟：20、30、40、50、60分钟，支持暂停、继续和结束；隐藏桌宠后仍继续计时，到时通过托盘通知提醒。
- 接入完整番茄钟动画：坐下拿书、阅读翻页、放书托腮、继续拿书、闭眼伸懒腰，以及向镜头扔番茄。自然到期与手动结束都播放结束动画，番茄酱糊屏停留后淡出回到待机。
- 运行或暂停时，悬停角色可看到8bit云朵剩余时间气泡；暂停数字冻结，移开即隐藏。
- 移动选项整合为“移动 >”悬停垂直子菜单，番茄钟控制也集中于独立子菜单。
- 修复番茄钟画面下无法右键、悬停无响应的问题：主窗口绘制真实输入表面，辅助窗口只绘制画面溢出部分，避免鼠标穿透与边缘重复叠色。
- 保留原拖动后领锚定、缩放、双击跳舞、长按火箭、随机动作、滑板/散步、睡眠及设置记忆。

Windows便携包解压后运行 `ArcPet.Preview.exe`，需要.NET Framework 4.8。升级时先退出旧版，可复制旧便携目录的 `data` 文件夹到新版目录以保留偏好。发布包不含个人设置。番茄钟会话退出后结束，不跨重启恢复；系统通知受Windows通知设置控制。

阶段切换会等待当前循环或过渡结束，以保持姿势衔接；结束动画完成前不能开始下一轮。番茄钟期间暂停随机、睡眠及双击/长按动作，退出后恢复。

32段动画、1165个PNG播放位置，1376项核心与窗口检查通过。另在内存配置验收宿主中用真实鼠标确认阅读时右键开菜单、悬停显示像素时间；不宣称真实等待完整20分钟。
