# ArcPet 0.20.1 · 桌面程序

C# / WPF / .NET Framework 4.8，无新增NuGet依赖。安装继续使用dist/ArcPet-v0.9固定路径，以保留开机启动登记和根目录data偏好；文件版本为0.20.1。32段、1165个正式PNG播放位置以根anime为唯一程序资产来源。

## 当前交互

| 输入或条件 | 行为 |
| --- | --- |
| 锁定或未锁定时有效双击 | 12轮跳舞，随机起始朝向，每3轮镜像；可抢断普通随机动作 |
| 锁定下长按500ms | 普通蹲跳；完整蹲下后才起跳 |
| 锁定下继续按住1500ms | 整脸渐红、脚底起火，松开发射并回原处 |
| 解锁长按后拖动 / Ctrl+左键拖动 | 按住左键满0.5秒拎起，松手落地 / 直接缩放0.4x—2x |
| 单击或右键 | 更新活动时间，不打断普通随机动作 |
| 滑板/散步途中任意鼠标输入 | 独立停止滑行并消费停止点击 |
| 睡眠中首次左右键 | 唤醒并清除点击历史，不立即跳舞或蹲跳 |

双击按两次点击间隔350ms、位置距离8DIP识别；实际拖动、缩放、右键或捕获取消清除双击候选。主程序使用16ms计时更新，按单调时钟选择当前正确帧，不补播过期帧。

## 睡眠与趴姿

无左右键交互满5分钟后具备睡眠条件。普通随机动作、跳舞及滑板/散步行程先完成，再评估最新活动时间和睡眠开关。每次真正进入睡眠时统一抽选：Next(0,3)==0采用lying，其余采用sleep，即1/3与2/3。两种都使用Phase=sleep、IsSleeping=true，左右键唤醒、关闭睡眠唤醒、120000ms自然醒来的逻辑完全共用。只在入睡时选择一次，不逐轮重新抽选。

lying不进入60—90秒普通随机池；该池仍为进食、思考、音乐、做操、电话及符合条件的移动动作。做操两轮、思考三轮、其余普通动作五轮；跳舞保持12轮。趴姿36帧、1600ms循环，睡眠最多播放两分钟，不适用五轮规则。气泡仅识别待机和思考，趴姿睡眠不显示气泡。

## 大小与资产

用户确认的design/lying-v1整尾浅弧原画通过tools/import_lying_v0_16.py导入anime/lying。按记录的暖色头部像素边界校准，整幅等比1.0875，平移(-46,-25)，所有36帧使用同一个变换。待机头宽160px、趴姿159px，头中心137/137.5px；可见落地基线均292px。尺寸测量是辅助，最终以对照图与实机观感验收。

没有逐帧拉伸、旋转或造姿势，原已确认设计帧保持不变。窗口本身的大小和位置不因睡眠改变，原缩放设置继续统一作用。校准记录及对照图见docs/desktop-v0.16-validation/lying-size.json和size-comparison.png。

## 模块边界

- ArcPet.Animation：帧、逐帧时长、通用播放时钟与JSON目录加载；不依赖WPF或输入。
- PetBehaviorController：输入识别、随机动作、统一睡眠入口与退出；只发出播放请求。
- PetWindow / FrameCache：窗口、手势适配、缓存及显示，不按具体姿态另建睡眠计时器。
- HorizontalTravel：共享水平行程与边界计算，注入选定动作的左右片段；行为层以独立travel阶段处理任意输入停止，普通动作打断仍走原手势识别。
- VerticalFlight / RocketArtworkWindow：独立火箭位移和火焰层，保存飞行原点。
- MoodBubbleController / MoodBubbleWindow：观察最终阶段，不反向控制角色播放。
- ArcPet.Settings / StartupRegistration：后台原子保存、恢复设置和当前用户开机启动开关。

测试采用内存或隔离设置和自启动存储，不写用户真实偏好或开机启动项。锁定点击用WPF路由事件；未锁定拖动/缩放用生产适配器，因为合成事件不能改变物理按钮状态。边界时序由测试时钟推进，不伪称等待了两分钟或完成实物鼠标验收。

package_desktop_v0_20_1.py核对当前安装目录dist/ArcPet-v0.9与0.20.1发布验证记录后，按需生成ZIP及SHA256文件；重新编译版本需重新建立验证记录。update_runtime_v0_20_1.ps1用于将已验证的0.20.1构建更新到原路径，保留设置及自启动。分发包不带data。旧版本打包/更新入口已清理，可从Git历史查看。


## 0.17 · 散步与滑板共享移动

待机60—90秒的随机池继续只保留一个移动名额，启用移动、未锁定、可见且有安全空间时才加入。抽中移动后单独Next(0,2)，滑板与散步各1/2；同一行程固定动作，短程返程只切换左右片段，不再次抽选。TravelRequested携带动作名，桌面据此注入对应片段给HorizontalTravel，动画播放接口保持通用。

两种动作均按较远端选择初始方向，保持窗口Top不变；长程到安全边界结束，短程预期5w后返回，双向均检测边界。边距按所选动作可见范围计算。散步左右各30帧/1200ms，换向标记为0、15双支撑附近姿势；滑板保留原有标记。移动不受普通动作固定轮数限制，睡眠等待完整行程结束。

单击、双击、长按、右键、中键、滚轮均立即停止移动并消费停止输入；锁定、隐藏或更改移动模式也会停止。普通随机动作可被有效双击或有效长按抢断，单击、右键、阈值前移动及 Ctrl 缩放期间继续播放普通动作。

正式资产anime/walk_left、anime/walk_right来自已批准的design/walk-v4首尾修订稿。按待机站立高度对整幅统一缩放1.01875，平移(-22,-6)，左右围绕固定身体中心x135镜像；所有帧同一变换，保留45°侧身的头宽透视和原头身比例。可见落地线291—292px，对照见docs/desktop-v0.17-validation/walk-size-comparison.png。tools/import_walk_v0_17.py可重建。

## 0.18 · 长按拎起

PetWindow 在左键捕获期间检测500毫秒阈值，随后在240毫秒内把原点击偏移平滑过渡到后领偏移。拎起与悬挂按当前帧的后领坐标和角色缩放调整窗口原点，光标静止时也会补偿动画中的后领位移。PetBehaviorController 播放拎起、悬挂与落地，快速松手时缩短剩余拎起帧。悬挂松手按已显示帧选择最短收势。拖动帧384×384相对于原窗口偏移(-32,-64)，最终共用待机姿势。

## 0.19 · 折叠菜单与独立番茄钟

桌宠右键和托盘均改用原生悬停展开的“移动”垂直子菜单，长/短/关闭与原存储和行为逻辑共用。
“番茄钟”子菜单含20、30、40、50、60分钟、剩余时间、暂停/继续和结束。运行或暂停时禁用新时长，避免误重置；完成后可直接开始下一轮。

PomodoroTimer独立放在ArcPet.Behavior，输入为单调毫秒时钟，不依赖WPF、动画播放或PetBehaviorController。暂停保存精确剩余毫秒，继续重设截止时间，延迟刷新仍只完成一次。PetWindow现有定时器驱动它，隐藏后继续计时；到时非阻塞托盘提醒，并持续显示完成状态。现有随机/移动/睡眠不受影响，番茄钟动画及会话跨重启恢复未接入。

构建：app/build.ps1 -Test -OutputDirectory dist/ArcPet-v0.19；窗口回归：app/test-windows.ps1（默认0.19），-PomodoroOnly可单独验证。新增核心测试覆盖全部时长、暂停/恢复、取消、截止边界、延迟完成与重复操作；窗口测试使用隔离配置验证双菜单、原生子菜单展开、控制命令、隐藏完成及不发起动画。测试时钟推进不代表真实等待20分钟。

## 0.20 · 番茄钟动画与悬停时间气泡

已确认的开始v3、阅读v3、暂停v3、继续、伸懒腰及番茄糊镜头稿正式导入番茄钟七个阶段；阅读阶段使用三个片段共用同一组透明 PNG。tools/import_pomodoro_v0_20.py对整场景使用同一个0.82等比视口变换及384px扩展画布；不改局部头身或原画。回待机的淡出以原生待机PNG垫底，结束末尾补足原循环后再回idle，避免二次缩放和重置姿势。

计时从选定时长立即开始。PomodoroSceneController独立管理阶段，PetBehaviorController在pomodoro阶段把播放权交给它。开始→阅读循环；暂停立即冻结计时，等当前呼吸、眨眼或翻页片段结束后放书→托腮循环；继续立即恢复计时，托腮循环结束后拿书→阅读。快速连点只更新期望状态，不裁断已开始的过渡。手动结束和自然到期都等待衔接点，再放书伸懒腰→掏番茄/糊屏停留1050ms/淡出750ms→待机。从托腮结束先拿书接回阅读，再完成同一退出链。结束期间禁用新一轮，最后刷新空闲时间，避免结束后立即睡觉。

番茄钟场景优先于原随机动作、睡眠和双击/长按交互；右键可控制番茄钟、隐藏及原设置，Ctrl缩放仍有效。开始时停止旧滑行并保存当前位置，若原在火箭飞行则先还原原点；结束后原逻辑恢复。隐藏不暂停计时或场景推进，回到前台显示当前阶段；退出程序不恢复会话。

计时或暂停中，光标悬停角色/场景的非透明像素时，原8bit云朵气泡显示MM:SS，离开立即隐藏；菜单展开、结束阶段及隐藏时不显示。时间数字使用3×5方格字形绘制，不依赖系统字体；云朵仍依次淡入，数字不越出主云。暂停冻结数字，读秒变化不重启云朵淡入。气泡保持穿透鼠标，不阻挡交互或改变窗口尺寸。原待机/思考心情气泡在番茄钟结束后恢复。

构建输出改为dist/ArcPet-v0.20，窗口回归默认0.20。新增场景核心检查及窗口组合截图见docs/desktop-v0.20-validation。合成时钟推进覆盖长计时与各阶段，不能代替用户对实际鼠标及动画美术的验收。

## 0.20.1 · 番茄钟右键和悬停修复

根因是扩展画面分支把主窗口sprite.Opacity设为0：透明分层窗口没有可见alpha时会被Windows原生命中穿透，WPF路由和IsMouseOver都无法得到真实输入。原程序化测试直接调用悬停及菜单逻辑，未覆盖此缺陷。

修复为主窗口绘制实际帧的320×320核心区域，扩展窗口用排除几何只绘制核心以外的区域，既保留原生输入表面，也防止半透明边缘重复合成。位置、大小、384/440px外延及素材不变；所有扩展动画共用修复。

新增主窗口渲染alpha、核心裁剪、辅助窗口排除核心及右键事件未被消费的回归。另用同一生产窗口的内存设置验收宿主，通过真实鼠标右键确认阅读中菜单展开，关菜单保持光标停在脸上可见时间气泡。验收宿主仅为便于工具发现而显示任务栏，不写真实配置；正式程序继续托盘运行。原开始/暂停/继续/结束时序未变。

2026-11-10 阅读节奏：每次进入阅读以及翻页开始时分别抽取下一次翻页的 10～12 秒间隔，等待期间重复原呼吸姿势；翻页保留原 23 帧和时长。眨眼目标平均间隔约 3.74 秒，翻页期间延至下一组呼吸。当前本地验证版在 `dist/ArcPet-reading`，旧 v0.20.1 发布校验记录仍对应发布时的构建。
