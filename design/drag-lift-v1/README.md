# 拖动动作设计 v1

2026-11-05。参考挂件照片中的悬垂姿态；角色服饰、配色、眼睛和头身比例以 ArcPet 待机帧为基准。使用内置绘图先画六张关键姿势，再绘制三段原画图集，并补绘悬挂收势、半蹲站起的过渡。

[可暂停、半速、逐帧的预览](review.html) · [完整 GIF](preview.gif) · [关键姿势](key-poses.png)

拎起段头部比例已修订。以内置绘图调整离地和收势的两张原画图集，按各自图集统一归一整人比例。发廓宽度由约 133–142 px 收敛到 139–145 px。逐帧检查了鞋底位置、透明留白与悬挂衔接。[补绘提示词](docs/head-correction-prompts.json) · [检查记录](docs/head-correction-verification.json)

| 阶段 | 帧数与时长 | 动作 |
| --- | --- | --- |
| [拎起](lift.gif) | 18 帧，0.74 秒 | 后领拉紧，肩膀带起身体，靴底离地，手脚下垂，摆动逐渐收住。 |
| [悬挂](hold.gif) | 16 帧，1.19 秒/轮 | 保持后领受力，尾巴伸展再收回，脚尖轻摆；包含半闭、闭眼、半开的眨眼。 |
| [放下](land.gif) | 21 帧，1.04 秒 | 后领松开，双手抬高，视线下移；衣裙和发梢随下落抬起，触地后半蹲缓冲，再收手站直。 |

透明 PNG 位于 `anime/lift`、`anime/hold`、`anime/land`。画布统一为 384×384，预览落地线 y=356；每张图集仅做整图等比归一和角色定位，不逐帧拉伸身体。悬挂以头部高度为定位参考，鞋底保留轻摆；触地后的鞋底位于同一落地线。弃用了一张站起过头的中间画，导出顺序和逐帧停留时间见 [timing.json](docs/timing.json)。

拎起终点、悬挂起点及放下起点共用同一张悬挂姿势；放下终点与拎起起点均使用待机基准。已核对 55 张 RGBA 帧的画布边界、独立角色区域、相邻阶段的共用姿势、悬挂首尾及 GIF 时长。原画在 `sources/`，[内置绘图提示词](docs/prompts.json) 与 [导出检查](docs/verification.json) 一并保留；重建入口为 `tools/build_drag_lift_preview.py`。

该稿已接入0.18。正式帧由 tools/import_drag_v0_18.py 导入。拎起与收势的两份初稿图集已由头部修订稿替代，历史提示词记录其原始输入。
