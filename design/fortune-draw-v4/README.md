# 抽签动作 v4

[完整预览](fortune-draw.webp) · [摇筒循环](shake.webp) · [签子逐帧特写](shake-detail.png) · [提签逐帧特写](draw-detail.png)

三支签统一为浅竹色、同样的宽度和圆角端头。拿到手中的签沿用相同样式。所有播放帧都检查了签面，去掉了色标、横纹和文字。摇筒时三支签按左、中、右先后升高，签杆在自己的位置进入筒口。提签时手握住左侧那支向上提，另两支留在筒里。

参照基准图与正式待机帧用内置绘图重画完整角色。外轮廓换成较细的灰棕线，发束用浅暖金和红棕阴影分块，衣料用白与深蓝色块。黑色裤袜和棕色短靴各自保留。修订后仍有少量柔和过渡色，摇筒转向时发梢也有轻微的手绘差异。

32 张整人画帧，摇筒一轮约 1.29 秒，完整预览约 5.68 秒。逐帧查看了签的外观、筒口遮挡、跨段衔接和深浅底轮廓，校验了裁剪、脚底基线及 WebP 解码。气泡「上上签」为预览示例。

阶段帧序见 `animation.json`，可用 `python tools/build_fortune_preview.py` 重建动画；也可用 `--output` 写到独立目录做核对。[内置绘图提示词](sources/prompts.json) · [验证记录](verification.json)

已接入 v0.21.0。正式帧由 `tools/import_fortune.py` 导入，结果气泡由程序在亮签时绘制。
