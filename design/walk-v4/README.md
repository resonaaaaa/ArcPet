使用内置绘图重新绘制直立关键姿势，再绘制两个互补的16姿势完整角色图集。胸颈回到髋部上方，缩短跨步；按承重、抬跟、屈膝经过、伸腿落地组织两侧步伐。近侧腿保持前景，远侧腿在其后经过；白衣保持简单块面，头发、衣裙和尾巴保留轻微变化。

当前选用30张不同的完整角色原画，每帧40毫秒，一轮1.20秒。其中28张来自两个互补图集，开头两张为本次首尾衔接专门修订的整人原画。各来源仅整人等比缩放，再以裙部中心和鞋底定位；没有局部变形、旋转肢体、混合补帧或固定上身拼装。图集末尾越入下一半步的姿势已重新排入相应半步；first-half的2号、second-half的1号因脚部轨迹倒退未采用，完整次序记录在anime/animation.json。

补帧试稿曾出现躯干长度或头型跳变，均未用于最终动画。当前选用原图位于sources，直立关键姿势位于docs/upright-keys.png；[绘图规格与来源](docs/prompts.json)，重建入口为../../tools/build_walk_v4.py。

已检查30帧独立性、透明区域提取、输出留白、统一尺度，以及GIF/WebP均为30帧/1200毫秒。全部腿部放大图用于复核遮挡。领口与裙部位置、相邻像素差只作诊断，不能证明解剖透视或动画观感合格；整体效果已获用户认可，实机位移观感继续观察。

## 首尾高度微调

用户已认可本版整体效果，另指出回到第1帧时突然变高。本次使用内置绘图修订000、001两张完整角色姿态，收回头颈和呆毛的高度突变，再与029、002衔接；其余28张PNG逐字节一致，帧数与节奏不变。输出图最高非透明点首尾差由12px减为1px，领口高度差由6px减为3px；这些数值只作诊断，保留自然姿态变化，该修订已获用户确认。

## 程序接入

满足原移动触发条件时，与滑板各1/2概率；沿用长短移动、较远端方向、水平高度、碰壁、任意鼠标输入停止及睡眠排队。短程不重新抽选动作。正式帧共用站立尺度变换并按固定身体中心镜像，见../../docs/desktop-v0.17-validation/walk-import.json。
