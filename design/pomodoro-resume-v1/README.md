# 番茄钟 · 继续动画

从已确认托腮姿势出发，放下左手、双手握住原位书本、拿起打开，再进入原阅读循环。当前仅美术设计，未接入程序。

- **34个播放位置、33张不同完整PNG，3.57秒**。
- 新绘16张整人姿势：8张伸手/握书动作，8张拿书/开书中间帧。
- 复用17张已确认完整姿势（包含实际阅读呼吸/眨眼），按继续动作方向编排；末尾回到原阅读入口。未拆分头、躯干、四肢，也未局部缩放旋转人物。
- 固定桌椅、关闭的台灯、白色小雏菊与落桌书，人物及拿起后的书按接触/遮挡组合。

## 一致性检查

以已确认暂停v3和阅读v3直接控制造型/配色。剔除无家具候选中书本偏大、偏低的稿件，改用完整场景对照补绘；伸手图集按实际动作顺序排列，避免把并非对应中点的图强插进关键帧而产生手部回退。

新画仅做获准的RGB校色，白衣保持暖白平涂。导出副本中的掌心/纸张白斑以RGB填色清理，保留墨线、alpha和动作；已确认原始PNG与正式程序资产不变。阅读呼吸/眨眼直接引用真实绘制的原循环，保留实际胸肩、衣袖细微变化。

全部帧组合为完整场景复核，重点检查头身比、头型、发色/肤色/裙靴、两手与袖口、拿书/开书、裁剪与跨段。GIF解码、PNG留白、预览脚本和文件链接另外检查；数值通过不等于用户美术验收。仍有微小手绘轮廓差异，当前待用户确认实际节奏和连续性；浏览器内播放未实际验证。
