## 本次修改

上一版分件方案没有通过验收：头颈脱离、头身比例错误、角色与桌子穿模。数值检查通过不能证明该稿合格。v2已弃用，本版按用户最新要求始终把猫姬作为完整角色绘制。

使用用户补充的基准形象和正式待机作为参考，先画6张关键姿势，再在一张统一图集中绘制32张完整场景。每张都包括自然相连的头、颈、躯干、手臂、裙摆、腿靴、尾巴及桌椅道具。导出仅做透明场景提取、整幅统一等比缩放及固定网格定位；没有拆头、拼脚、局部缩放、旋转或变形造帧。

猫姬从桌后坐到凳子上；桌面和桌沿在腰及大腿之前，凳子和靴子在桌后。双臂前伸拿书，书始终在桌面上方。台灯关闭，右侧为白色小雏菊。嘴为小猫猫嘴，瞳孔向下看书，不安排抬眼。

## 时序

| 帧（1起算） | 动作 | 每帧 |
| --- | --- | --- |
| 1—6 | 桌后屈膝坐下 | 100ms |
| 7—14 | 一次轻微呼吸，胸肩和袖口有8张不同姿势 | 200ms |
| 15—18 | 双手前伸触碰闭书 | 100ms |
| 19—24 | 拿起并逐渐转正闭合的书 | 100ms |
| 25—32 | 打开封面、双手托稳 | 100ms |

32张448×448透明PNG，共4000ms。单次播放后停住，只表示开始动作结束；本轮没有阅读循环、暂停、扔番茄或程序功能接入。

## 复核与限制

已查看关键姿势、完整32帧及领口/手书放大对照，重点检查头颈连续、肩宽和头型、桌后坐姿、手腕与衣袖、手书接触及桌沿遮挡。8张呼吸姿势有不同胸肩衣袖像素，没有重复整人帧。

一张图集的所有场景共用相同的等比缩放和网格定位，不按每帧颜色检测结果移动整幅画面，避免检测误差制造桌面上下跳动。发色代表色的各通道跨度为2—4级，头部上半轮廓宽度约196—203px；这是原画诊断值，并非逐像素相同的保证。原画道具边缘仍有细微手绘差异，不能像旧稿那样宣称固定像素即已通过美术验收。

PNG留白、独立性、GIF单次播放/帧数/总时长、WebP帧数及预览脚本语法已检查。动画自然度、比例和画风仍以用户视觉验收为准。
