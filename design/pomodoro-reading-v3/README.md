# 阅读修订 v3 · 动作边界与尾巴

[开始接阅读 / 逐帧 / 半速](review.html) · [阅读GIF](reading.gif) · [翻页片段](page.gif) · [尾巴逐帧对照](docs/tail-review.png)

针对用户指出的眨眼/翻页前后跳变及翻页尾巴消失，进行了以下修订，等待视觉确认，未接入程序。

- 翻页的关键姿势和中间姿势以完整角色补绘尾巴，外侧金色弧线在动作过程中持续可见，并正确位于手臂、书和花盆后面；没有贴一条独立尾巴。
- 眨眼保留原本较稳定的完整角色轮廓，用已授权的RGB校色将过亮的眼皮填色统一为脸部桃色，保留眼线和仍睁开的白眼。重绘眨眼中有呆毛高度跳变的候选未采用。
- 循环采用同组阅读姿势，不再每次呼吸循环都插入另一批次的开始末帧，减少线条清晰度和轮廓切换的突变。开始资产全部保持原样；阅读入口不是相同图片，接续仍须视觉确认。
- 保留手带动书页、松手和收回的动作；仍为31张不同透明PNG、47播放位置、5610ms。呼吸是实际绘制的姿势循环，没有用单张静止帧填充。

## 检查与限制

查看了全部选用帧、尾巴外弧对照、眨眼连续对照与手书特写。尾巴区域金色像素检测作为漏画告警，所有帧均超过门限，不能替代遮挡和形态的视觉检查。首轮尾巴过高稿也已修订。

GIF解码逐帧与同一调色板量化后的PNG比较一致，未发现编码产生的空白/残留帧。材质固定取样继续匹配开始末帧，校色本身只改RGB、不改透明轮廓；尾巴原画补绘则会正常改变该部分轮廓。检查不是用户美术验收，仍保留少量手绘差异，不承诺所有运动像素相同。

原画在 `sources/`，整体补绘提示词在 `docs/prompts.json`，前后参考、尾巴可见性检查和导出记录在 `docs/`；播放帧在 `anime/reading/`。重建入口 `tools/build_pomodoro_reading_v3.py`，共用导出和RGB校色工具。内置浏览器file协议限制仍存在，未绕过；提供GIF与本地逐帧页面供用户查看。
