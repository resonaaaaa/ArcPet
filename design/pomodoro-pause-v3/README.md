本版直接以已确认的 `../pomodoro-reading-v3/anime/reading/000.png` 及其循环为颜色、头型和体型基准，取代未通过验收的暂停 v2。仍为美术稿，未接入程序。

- `reading-pause.gif`：已确认阅读 → 新暂停 → 两轮托腮，重点检查跨阶段接续。
- `pause-preview.gif`：暂停及托腮；`paused.gif`：单独循环。
- `review.html`：暂停/阅读接续/托腮、逐帧、半速、深浅背景。
- `docs/reading-pause-comparison.png`：已确认阅读与多张新托腮完整场景对照。
